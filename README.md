## ✨ 特性

- 🛡 **安全鉴权**：提供强化的授权逻辑、会话防劫持和会话同步下线机制。
- ⚡️ **高优内核**：内置最新的 mihomo 等高效内核协议套件。
- 🎨 **现代化 UI**：全面适配 iOS 与 macOS，并整合自适应主题切换的网页后台管理台（提供玻璃拟物化设计感和优秀的使用体验）。
- 🛠 **自定义扩展**：灵活的数据库模式、WebSocket 连接及参数灵活可配。

---

## 📦 核心模块

1. **终端客户端 (iOS & macOS)** - 包括主配置中心、安全连接节点及状态展示视图。
2. **后台管理台 (Web UI)** - 面向管理员提供的流量与用户控制、日志查阅功能面板，支持暗亮双色主题自适应流转。
3. **安全中间件 (Backend)** - 提供核心的认证下发接口及防篡改参数加密交互。

## 💬 反馈与建议

SkyProxy 的迭代离不开您的真实反馈与宝贵构思。遇到问题或有任何新的点子，请随时与我们分享！

### 🐞 提交使用上的 Bug（缺陷上报）
如果您在连接配置、后台查看或是设备流转中遇到任何异常崩溃，请采用如下方式定位和反馈：

- 前往 **[Issues 面板](#)**，点击 `New Issue`，并选取 **Bug Report** 模版。
- 所需提供的信息：设备系统环境（iOS 版本 / macOS 芯片）、复现路径、控制台日志或是出错时的界面截屏。

### 💡 提交优化建议与功能诉求（功能反馈）
觉得某个功能设计不够人性化，或是希望能实现新的加密/防劫持特性？

- 前往 **[Issues 面板](#)**，选择 **Feature Request** 模版。
- 如果有具体的界面构思想法，推荐在反馈框里附录您画的草图或简单说明。有探讨空间的问题也可以前往 **[Discussions 区](#)** 发起一个话题提问。
